# Digital Wallet Console App

A console-based digital wallet application developed using **Core Java**. The application allows users to register, log in, manage their wallet balance, perform transactions, and view transaction history.

## 📌 About the Project

The Digital Wallet Console App is a Java-based mini project created to practice core Java programming concepts through a practical wallet management system.

The application temporarily stores user accounts and wallet information using Java Collections and provides a menu-driven console interface for performing wallet operations.

## 🚀 Features

- User Registration
- Duplicate Username Validation
- User Login
- Wallet Balance Management
- Deposit Money
- Spend Money
- Insufficient Balance Validation
- Transaction History
- Menu-Driven Console Interface
